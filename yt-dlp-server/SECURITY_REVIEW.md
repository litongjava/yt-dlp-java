## 公网部署风险

1. `/xyz` 没有鉴权、限流、任务并发上限、下载超时或磁盘配额，可能被滥用消耗带宽和存储。
2. `id` 直接参与目录和命令参数拼接，未校验视频 ID，也未验证路径边界。存在路径及参数滥用风险；代码使用 ProcessBuilder，不能仅据拼接就断言存在 shell 命令注入。
3. `/download/**` 注册到框架文件处理器，需进一步验证路径限制及可读范围，避免暴露日志、cookies 或其他文件。本次未进行路径穿越实测。
4. handler 开启 CORS，应按实际客户端限制；CORS 不是访问控制机制。
5. 下载失败可能使 `result.getPath()` 为空，后续 `new File(path)` 抛异常；需补充输入校验和统一错误响应。

以上服务安全功能本次未修改，README 已明确当前边界。

## 公网地址核查

源码中存在的公网 URL 为 yt-dlp 官方 GitHub Releases 下载地址、YouTube 视频与播放列表地址，以及日志 XML 的 schema 地址（含 raw.githubusercontent.com）。未发现硬编码的自建业务服务器公网域名或公网 IP。测试代理 `127.0.0.1:10808` 是回环地址，不是公网服务器。

XML 命名空间/schema URL 是格式声明，不等同于业务 API；Maven 构建还会访问其配置的依赖仓库，实际视频解析也可能访问站点 CDN。这里的结论针对源码硬编码地址，不代表运行时只有这些网络请求。更新功能调用官方 yt-dlp 自更新器，需要访问其发布服务。
